# 🧠 Ram Dwarampudi — Machine Learning & Data Engineering Portfolio

A high-performance personal portfolio engineered with a **futuristic cybernetic / Linear-inspired dark glass aesthetic**, showcasing projects across **Machine Learning, Data Analytics, Data Engineering pipelines, and Algorithmic Problem Solving**.

🔗 **Live GitHub Repository**: [https://github.com/Ram-dwarampudi/portfolio](https://github.com/Ram-dwarampudi/portfolio)

---

## ✨ Key Features & Architecture

- 📊 **Machine Learning & Data Engineering Specialization**: Tailored for data science, predictive machine learning models, statistical distributions, telemetry pipelines, and agentic AI systems.
- 🔄 **Horizontal Scrollable Projects Carousel**: Left-to-right snap-scrolling project showcase (`scroll-snap-type: x mandatory`) with navigation buttons (`<` / `>`), mouse drag-to-scroll, touch swipe gestures, and category filter sync.
- 🎯 **Deep-Dive Case Study Modals**: Architectural breakdown for each project with challenge statements, engineering solutions, technical highlights, and direct GitHub links.
- ⚡ **Competitive Coding Integration**: Direct profile links and algorithmic summaries for **LeetCode** (`@Ram_Dwarampudi`) and **CodeChef** (`@ram_dwarampudi`).
- 💻 **Ram-CLI Interactive Workstation**: In-browser interactive terminal simulator with command history, autocomplete, and specialized commands (`leetcode`, `codechef`, `resume`, `skills`, `projects`, `sudo hire`).
- 🛠️ **Categorized ML & Data Arsenal**: Segmented into *Machine Learning & AI*, *Data Analytics & Pipelines*, *Core Languages & DSA (Python, Java, C)*, and *Tools & Platforms*.
- 🧭 **Spacious Collision-Free Navbar**: Wide navigation layout (1320px) with clean typography, dynamic status pill, and direct Google Drive Resume viewer.
- 📱 **100% Responsive & Zero Build Step**: Built with pure Vanilla HTML5, modern CSS3 glassmorphism design tokens, and modular ES6 JavaScript.

## 💻 Running Locally

### Option 1: Direct in Browser
Double-click `index.html` in Windows File Explorer or open it in any web browser.

### Option 2: Using Python HTTP Server (Recommended)
```bash
cd portfolio
python -m http.server 4200
```
Then navigate to `http://localhost:4200` in your browser.

### Option 3: Using Node / npx serve
```bash
cd portfolio
npx serve .
```

## 🌐 Deployment to Vercel or GitHub Pages

### Deploying to Vercel (Automatic Continuous Deployment)
1. Push any updates to the GitHub repository:
   ```bash
   git add .
   git commit -m "Update portfolio content"
   git push origin main
   ```
2. Connect your GitHub repository on [Vercel](https://vercel.com). Vercel will automatically build and deploy the static site on every push.
